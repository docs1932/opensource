# 1.下载
```
先连接 VPN -->
VPN 切换到 台区(或其他区域) -->
修改 iPhone 为台区(媒体与购买项目) -->
下载 WhatsApp  
```

# 2.注册 (截至 20250810 可用)
```
先连接 VPN -->
VPN 切换到 台区(或其他区域) -->
点击注册 -->
输入中国大陆的手机号即可 --》
填写信息后登录即可
```

# 3.加入群组 + 加联系人
```
可以在 Facebook / Instagram / Twitter / 微信 / QQ 等社交平台搜索群组，
加入即可 。
然后在群组里可以看到联系人信息，可以添加联系人。
然后可以做外贸了。。。
```
