## 使用约定

- 每篇知识笔记使用 `.md` 后缀，并在开头写一个一级标题。
- 可执行脚本、Dockerfile、Compose 文件和软件配置继续保留原始格式，避免失去可执行性。
- 新内容优先放入已有主题目录；找不到合适分类时，先放入对应主题的“待整理”页面。

更多本地启动与发布说明见：[Wiki 使用说明](Wiki-使用说明.md)。
