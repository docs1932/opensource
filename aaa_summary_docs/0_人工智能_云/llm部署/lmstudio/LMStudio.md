## 1.1 windows 安装
https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/2171

```
1.创建文件夹
D:\software\lmstudio\data
D:\software\lmstudio\app

2.创建 link:
2.1 管理员打开 cmd(非powershell)
2.2 mklink /J "C:\Users\<user>\.lmstudio" "D:\software\lmstudio\data"

3.右键 exe 安装至：
D:\software\lmstudio\app 目录

4.完成后使用即可
```
