## 1.1.1 windows 本地 docker 快速安装使用
```
1.需要先安装 docker desktop，然后配置好

2.安装并启动

docker volume create n8n_data

docker run -it --rm --name n8n -p 5678:5678 -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true -e N8N_RUNNERS_ENABLED=true -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

3.输入 http://localhost:5678/，注册并登录即可
```
