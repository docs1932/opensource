## 1.3 使用 fish
```
1.安装 fish
sudo yum install epel-release -y
sudo yum install fish -y
2.设置 fish 为默认 shell
chsh -s /usr/bin/fish
3.配置Fish（可选）
安装并设置Fish为默认Shell后，你可以开始配置它。Fish的配置文件是~/.config/fish/config.fish。
你可以在这个文件中添加你自己的配置和函数。例如，你可以添加以下内容来启用语法高亮和自动建议：
# ~/.config/fish/config.fish
set fish_color_autosuggestion brblack
set fish_color_command green
4.更新和卸载（可选）
# CentOS/RHEL (需要先卸载EPEL)
sudo yum remove fish epel-release
```
