# 4.实用知识
## 4.1 组件通信
### 4.1.1 @Input(绑定的是属性, 父传子) 和 @Output (绑定的是事件, 子传父)
```
例如我们抽取了一个新的 card component，我们希望这个 card component 可以被多个父组件所使用:
[input] 绑定的是属性
[output] 绑定的是事件

1.父组件传递数据给子组件
那么，我们如何将数据传递给 card component？例如：传递 cardList 数据，
此时，需要在 card component 中定义一个 input 属性，接收父组件传递的数据。
1.1 子组件定义 input 属性
@Component({...})
export class CardComponent {
    @Input() cardList: any;
}
1.2 父组件传递数据给子组件
那么，父组件中 cardList 数据，就可以通过 card component 的 input 属性进行传递了。
<app-card [cardList]="myCardList"></app-card>

2.子组件传递数据给父组件
那么，我们如何将数据传递给父组件？
例如：点击 card component 中的某个按钮，将按钮的索引传递给父组件，
2.1 子组件定义 output 属性
@Component({...})
export class CardComponent {
    @Output() messageEvent = new EventEmitter<string>();
    // 该函数可以绑定到某个按钮的点击事件
    sendMessage(msg: string) {
         this.message.emit(msg);
    }
}
2.2 父组件接收子组件传递的数据
--html 文件
<app-card (messageEvent)="handleMessage($event)"></app-card>
--ts 文件
handleMessage(msg: string) {
    console.log(msg);
}
```

### 4.1.2 viewChild
```
@Component({
  selector: 'app-layouts',
  templateUrl: './layouts.component.html',
  standalone: true,
  styleUrls: ['./layouts.component.less'],
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  imports: [HeaderComponent, FooterComponent, NzDropDownModule, NzBreadCrumbModule, NzIconModule, NzMenuModule, NzLayoutModule, BottomComponent]
})
export class LayoutsComponent implements OnInit, AfterViewInit {

  // 这里拿到子组件对象
  appHeader = viewChild(HeaderComponent);

  constructor() {
    console.log("appHeader in constructor: ", this.appHeader);
  }

  ngOnInit() {
    console.log("appHeader in ngOnInit: ", this.appHeader);
  }
  ngAfterViewInit() {
    console.log("appHeader in ngAfterViewInit: ", this.appHeader);
    // 在这里可以调用子组件里面的方法：
    console.log("调用子组件的方法：", this.appHeader()?.menuList);
  }

}
```

## 4.3 @Component 属性解读
### 4.3.1 schemas
```
import {  Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
@Component({
    schemas: [CUSTOM_ELEMENTS_SCHEMA]
})

解决的问题:
1.模板中使用 <xxx>报错“not a known element --> 
添加 schemas: [CUSTOM_ELEMENTS_SCHEMA]

2.集成 Web Components / 第三方自定义元素 -->
必须配合 CUSTOM_ELEMENTS_SCHEMA

3.微前端中嵌入子应用自定义标签 -->
使用 CUSTOM_ELEMENTS_SCHEMA 抑制错误


💡 总结：
CUSTOM_ELEMENTS_SCHEMA = “Angular，请信任这些自定义标签，别报错！”
它是 Angular 与 Web Components 生态互操作的关键桥梁 🌉
```
