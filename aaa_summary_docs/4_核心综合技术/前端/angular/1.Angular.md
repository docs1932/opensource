# 3.知识概念
## 3.1 前端数据缓存: cookie, localStorage, sessionStorage
```
@Component({
  //...
})
export class AppComponent implements OnInit {

  constructor() { }

  ngOnInit() {
    // cookie
    document.cookie = "theme=dark";
    // sessionStorage
    sessionStorage.setItem("theme", "dark");
    // localStorage
    localStorage.setItem("theme", "dark");
  }

}
```

# 4.实用知识
## 4.1 父子组件通信
```
例如我们抽取了一个新的 card component，我们希望这个 card component 可以被多个父组件所使用:

1.父组件传递数据给子组件
那么，我们如何将数据传递给 card component？例如：传递 cardList 数据，
此时，需要在 card component 中定义一个 input 属性，接收父组件传递的数据。
1.1 子组件定义 input 属性
@Component({...})
export class CardComponent {
    @Input() cardList: any;
}
1.2 父组件传递数据给子组件
那么，父组件中 cardList 数据，就可以通过 card component 的 input 属性进行传递了。
<app-card [cardList]="myCardList"></app-card>

2.子组件传递数据给父组件
那么，我们如何将数据传递给父组件？
例如：点击 card component 中的某个按钮，将按钮的索引传递给父组件，
2.1 子组件定义 output 属性
@Component({...})
export class CardComponent {
    @Output() messageEvent = new EventEmitter<string>();
    // 该函数可以绑定到某个按钮的点击事件
    sendMessage(msg: string) {
         this.message.emit(msg);
    }
}
2.2 父组件接收子组件传递的数据
--html 文件
<app-card (messageEvent)="handleMessage($event)"></app-card>
--ts 文件
handleMessage(msg: string) {
    console.log(msg);
}
```

## 4.2 符号
```
[] 表示绑定属性
( ) 绑定事件
[()] 绑定双向数据绑定
```
