

# 扩展

## pgvector & pg_trgm
```
pgvector是 PostgreSQL 用于高维向量存储与相似度搜索的扩展；pg_trgm是 PostgreSQL 用于基于三元组（trigram）的文本模糊匹配与相似度计算的扩展。
核心功能对比

    pgvector：专为 AI 应用设计，支持存储嵌入向量（如 LLM 生成的 768 维向量），提供余弦距离、欧氏距离等度量，支持 HNSW/IVFFlat 索引实现近似最近邻搜索（ANN），可混合查询关系数据与向量数据 。
    pg_trgm：专为文本搜索设计，将字符串拆解为连续 3 字符组（trigram），支持 similarity() 函数计算相似度、% 运算符判断相似性，并能加速 LIKE '%...%' 模糊查询（通过 GIN/GiST 索引避免全表扫描）。

典型应用场景

    pgvector：语义搜索（文档检索）、以图搜图、推荐系统（相似物品/用户）、RAG 架构中的知识库召回。
    pg_trgm：纠错搜索（处理拼写错误）、去重（相似名称/地址匹配）、模糊关键词检索、自动补全建议。

关键区别总结
```
| 维度 | pgvector | pg_trgm |
| --- | --- | --- |
| 处理对象 | 数值型高维向量（float/half/sparse） | 文本字符串（Text/Varchar） |
| 核心算法 | 向量空间距离计算（L2/Cosine 等） | 字符三元组集合交集/并集计算 |
| 索引类型 | HNSW, IVFFlat | GIN, GiST (trgm_ops) |
| 主要用途 | 语义理解、AI 特征匹配 | 拼写容错、模糊文本查找 |

# 概念
```
一、AI领域核心术语重定义

向量（Vector）‌
AI领域特指‌特征向量‌，是把文本、图像、音频等非结构化数据，通过Embedding模型转化成的一组有序浮点数，用来表征数据的语义/视觉特征，是向量数据库的核心存储对象。

维度（Dimension）‌
指向量中独立数值的总个数，比如768维向量就包含768个特征维度，不同维度分别对应语义、纹理等不同类型的特征信息，维度越高承载的细节特征越丰富。

温度（Temperature）‌
大语言模型的核心超参数，取值范围通常0~2，用来控制生成内容的随机性：数值越高输出越发散、创意性越强，越低输出越确定、逻辑越严谨。

二、AI领域的Score（分数）

AI领域的Score是‌量化模型输出质量、匹配度、置信度的核心数值指标‌，不同场景下有明确的专属含义：

生成艺术场景‌：CLIP Score 衡量生成图片和提示词的图文匹配度，Inception Score 评估生成图片的清晰度与多样性。
向量检索场景‌：相似度Score 表示两个向量的语义/特征匹配程度，通常基于余弦距离、欧氏距离计算得出。
医学AI场景‌：比如SCORE-AI 模型输出的异常判定Score，用来量化脑电图异常的置信度，辅助医生做临床决策。
分类任务场景‌：模型输出的分类Score 代表样本属于某一类别的概率，数值越高分类结果的置信度越强。
```
