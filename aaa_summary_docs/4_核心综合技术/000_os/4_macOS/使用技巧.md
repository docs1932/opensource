# 2.下载安装软件
## 2.1 下载安装 homebrew
```
1.打开终端（黑窗口），执行如下命令（最好是有梯子）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2.验证是否安装成功
brew --version
```

## 2.2 安装 bash
```
brew install bash

查看新版 bash 安装路径(假定 /opt/homebrew/bin/bash)
which -a bash

验证版本：(应该看到的是5.x版本或者更高)
/opt/homebrew/bin/bash -version

配置环境变量，如果文件不存在则创建
vi ~/.zshrc
vi ~/.bash_profile

# 确保 Homebrew 的路径在 PATH 中优先级更高
export PATH="/opt/homebrew/bin:$PATH"

# 重新加载配置文件
source ~/.zshrc
source ~/.bash_profile

# 打开新的终端查看版本是否是 5.x 
bash --version
```
